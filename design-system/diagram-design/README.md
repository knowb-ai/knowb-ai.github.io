# KnowB Diagram Design System

This is the local, branded diagram system for KnowB AI Systems. It inherits the complete Diagram Design grammar and uses the KnowB Autumn palette as its required skin.

Start here:

1. Choose one diagram grammar in [`SKILL.md`](SKILL.md).
2. Read the matching file in `references/` before drawing.
3. Apply only the semantic roles in [`references/style-guide.md`](references/style-guide.md).
4. Start with [`../../static/diagrams/knowb-diagram-template.html`](../../static/diagrams/knowb-diagram-template.html) for public diagrams.
5. Keep output self-contained: HTML, inline SVG, no runtime dependency, no shadows, and no more than two focal nodes.

The public showcase lives at `/diagrams/`. It demonstrates the approved skin and links to the full-size reference system map.

See [`UPSTREAM.md`](UPSTREAM.md) for license and upstream provenance.
