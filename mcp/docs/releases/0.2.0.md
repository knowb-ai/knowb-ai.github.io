# knowb-org-index 0.2.0 release candidate

Status: candidate. Publication and the shared knowledgeHQ client switch require
separate approval after the P6 gates pass.

## Support

The candidate support claim is maintained in
[`release/support-matrix.yml`](../../release/support-matrix.yml):

- macOS ARM64 (`aarch64-apple-darwin`, macOS 11+ wheel tag);
- Linux x86_64 (`x86_64-unknown-linux-gnu`, manylinux 2.17 wheel tag).

macOS x86_64, Windows x86_64, Linux ARM64, and Windows ARM64 are excluded until
their native build and installed-runtime evidence is recorded. Python 3.11–3.14
is tested for each advertised target.

## Contents and provenance

Each target release record must include the exact wheel and sdist, SHA-256
`checksums.txt`, CycloneDX `sbom.cdx.json`, `licenses.json`, and
`release-manifest.json`. The manifest records the source commit, package version,
target, build metadata, and pinned okf-rs revision
`6d52cc7ad0b5afea2e0001779b4498e268905ddc`.

Archives must contain no knowledgeHQ registry, source corpus, credentials,
`.env`, SQLite state/WAL files, or website output. The packaged bridge is the only
native payload in a wheel.

## Runtime and optional capabilities

The core connector runs from the installed wheel over local stdio. Search, read,
context, and health do not require the website checkout, Cargo, Git, `gh`, or
runtime network access. GitHub and Google design-vault actions remain explicit
optional capabilities, with proposal/confirmation and identity/ACL checks.

New folder state defaults to the platform user-state directory keyed by the
canonical registry path. Existing knowledgeHQ registries retain their explicit
`../.knowb-state` location and are not relocated or rewritten.

## Migration and recovery

Stop the current MCP process, create an SQLite online backup with
`mcp/scripts/backup_sqlite.py`, and record its checksum before changing the client
entry. Generate the installed command with `knowb-org --config PATH client-config`,
review it, then apply it as a separate approved change. Preserve the previous
checkout command and client file.

For rollback, reinstall the prior connector in an isolated environment, point it
at the preserved registry and SQLite backup, and verify project IDs, allowlists,
citation paths, pending confirmations, audit history, expiry, and replay behavior.
No destructive cleanup or database rewrite is part of this release.
