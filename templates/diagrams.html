Inherited System · KnowB Autumn Skin

Diagrams that make the system easier to trust.

KnowB AI Systems inherits the editorial diagram grammar from Diagram Design and applies a local Autumn token layer. The result is a small set of precise, self-contained diagrams for architecture, decision flows, governance, and knowledge operations.

Operating rules

  • One diagram grammar per question.
  • One or two focal elements, never a rainbow.
  • Inline SVG and accessible text alternatives.
  • KnowB Autumn colors only.

How to use it

Build the explanation, not decoration.

The local system includes all inherited type references, icon primitives, and templates. Start from the branded template, use semantic roles instead of raw colors, then keep the finished diagram as a portable HTML and SVG surface.
