# KnowB pixel icon dictionary
#
# Every icon is an 8x8 map, two colours at most:
#   #  the icon colour
#   o  a detail punched out of the shape (rendered in the `cut` colour,
#      which should match the surface the icon sits on)
#   .  empty
#
# Each entry starts with `name: meaning`, followed by exactly eight rows.
# Rebuild templates/pixel_icons.html after editing:
#   python3 scripts/build_pixel_icons.py
