KnowB's project RFPs are open to outside builders through the **RFP Connector**, part of the open-source BetterHackdays project. It runs inside the coding agent you already use, as an MCP server, or over REST.

## What you can do

- Browse the approved public RFPs and the live projects behind them, and compare them side by side.
- Check a new idea against the public idea catalogue, the open projects, and the [project showcase](/#use-cases).
- Send a refinement, an expression of interest, or a contribution request to the maintainers, with your identity verified by GitHub.

## How requests work

Every request is reviewed by a person. A request is not a grant: submitting one never changes who can work in a repository, and access only follows the repository owner's explicit approval.

## Get started

The connector manual covers setup, the full tool reference, and the request rules. For anything that is not about RFPs, write to [ping@knowb.run](mailto:ping@knowb.run).
